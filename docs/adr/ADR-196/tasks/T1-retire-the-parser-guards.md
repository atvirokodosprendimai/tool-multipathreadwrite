# Task ADR-196-T1: require urfave/cli v3.14.0 and retire the guards that modelled v3.11.0

**Depends-on:** none
**Covers:** none — no spec
**Estimated scope:** M
**Owner:** unassigned
**Produces:** `TestTheParserHandsMrwOnlyWhatWasTyped`; `TestAPaddedPathIsNeverServedAsItsTrimmedSibling`; contract §128, §134–§139 retargeted
**Consumes:** none
**Data dependency:** hermetic
**Proof map:** v1
**Rests-on:** `no delivered string is untyped`, `a padded path never serves its trimmed sibling`, `the guards are gone`

## Goal

`go.mod` requires `github.com/urfave/cli/v3` v3.14.0, the four functions that modelled v3.11.0 are gone, and two tests hold the promise ADR-069 made: the parser hands mrw only what was typed, and a padded path never reaches its trimmed sibling.

## Ordered Steps

1. [S1] Write `cmd/mrw/parser196_test.go` and see it RED on v3.11.0:
   - `TestTheParserHandsMrwOnlyWhatWasTyped`: the 2026-11-10 probe made permanent. Random argv over every subcommand but `mcp`, `seen`, `instructions`, `version`, `skill` and `hook`, every own and inherited flag, padded names, attached and separate values, `--`, `-`, padded `-` and a dash before a digit, through `parserDelivers`; each delivered string must be a typed token or the text after `=` in one. `MRW_STRESS_N` (default 300) and `MRW_STRESS_SEED` as today, a bad value fatal. Logs the dispatched-case count and fails if it is zero.
   - `TestAPaddedPathIsNeverServedAsItsTrimmedSibling`: in process (`runIn`; once the guards are gone `main` adds no argv check, and contract §128 drives the binary), a tree holding only `x` (content `plain`): `read 'x '`, `read ' x'`, `read 'x\t'`, `read -- 'x '`, `read --grep plain 'x '` and `write` of a plan naming `x ` each exit non-zero and never serve `x` nor change it; the pair: `read x` serves `plain`. It needs no file named `x `, so it runs on Windows.
   On v3.11.0 the first must be RED; the second passes there too, since the guard refuses with exit 2. Record both runs.
2. [S2] `go get github.com/urfave/cli/v3@v3.14.0`; `go mod tidy`. [proof: acceptance]
3. [S3] Remove `refusePaddedArgs` and its six call sites, `refusePaddedFlagValues` and its call in `main`, `padAttached`, and `liftLoneDash` with its call in `main`. Correct `flagRole`'s lone-`-` comment (v3.14.0 keeps it and parses on) and `shortRoot`'s comment. Mutants, each killed:
   - pin urfave back to v3.11.0 (`go.mod` only): the property test goes red;
   - `TrimSpace` each positional at the top of the read Action: the sibling test goes red.
   [proof: mutation]
4. [S4] Run `go test ./cmd/mrw` and handle each red test: a test a done task locks keeps its name and is retargeted at what v3.14.0 does with the same argv; one no task locks and whose subject is gone may be deleted. List every retargeted test in the PR body, then lint every record and relock each lock that moved. [proof: acceptance]
5. [S5] Retarget contract §128 and §134–§139, keeping each `# NNN. ` header, each pairing the new behaviour with the case that must fail: §128 `read 'x '` serves `x `'s content with both present, and with only `x` exits 1 naming `x ` and never prints `x`'s content; §134 `--files-from='list '` reads the list named `list `; §135 `'--no-numbers ' 'x '` serves `x ` with numbers off; §136 `write --root -- --root='dir '` is refused by the parser or names `dir `, never `dir`; §137 `printf plan | mrw write - --dry-run` writes nothing, and `write - x` exits 2; §138 `write ' - '` names the path ` - `, not standard input; §139 `read ' -1= ' '-1='` serves both. [proof: acceptance]
6. [S6] Run `./scripts/contract.sh`, `./scripts/static.sh` (fence-prose names any done fence the change turned red) and `go test ./...`. [proof: acceptance]
7. [S7] `TestALoneDashThenATerminatorWritesThePipedPlan` (`cmd/mrw/parser196_test.go`): `printf PLAN | mrw write - --` creates the planned file, exit 0; the pair: `write - --dry-run --` writes nothing and `write - x` exits 2, writing nothing.

# Receipt fields mrw has shipped (ADR-111). One line per key path: the receipt, then the path.
# Nested keys join with ".", a list's elements are "[]", a map's values are "{}".
#
# A caller may rely on every key here: it keeps its name, its JSON type and its meaning, and keys are
# only added. A new key is appended in the change that adds it; a removal, a rename or a change of
# meaning waits for a major version and is named as going in the release before it.
# cmd/mrw's TestNoShippedReceiptFieldDisappears and internal/mcp's TestNoShippedMCPReceiptFieldDisappears
# hold the receipt types to this file both ways.

# write          mrw write --json            check          mrw check --json
# check_refusal  a mrw check --json refusal  stats          mrw stats --json
# mcp_write      mrw_write's structured value
# mcp_read       the receipt mrw_read carries in content[1] (ADR-023)
